# 個人用コード譜・練習アプリ 要求定義書（v0.2 ドラフト）

最終更新: 2026-09-30
ステータス: ドラフト

変更履歴:
- v0.1 (2026-09-27): 商用・ユーザー投稿型サービスとして作成
- v0.2 (2026-09-30): **個人用ツールに方針転換**。権利処理・投稿・課金・広告・モデレーションの要件を削除

---

## 1. 目的

U-FRET・楽器.me の代わりに、**自分が持っている譜面を快適に弾いて練習するための個人用 Web アプリ**を作る。

既存サービスへの不満のうち、次の2点を自分用に解消する。

- 広告が多い・重い → 広告ゼロで、軽く、演奏中に何にも邪魔されない
- 練習機能が弱い → 音源に合わせる、区間を繰り返す、コードの響きを確かめる、練習を記録する

公開サービスにはしない。譜面を不特定多数に配信しないので、歌詞の許諾（JASRAC・NexTone）は不要になる（→ 2.1）。

---

## 2. 前提・制約

| 項目 | 内容 |
|---|---|
| 利用者 | 自分だけ（シングルユーザー） |
| 公開範囲 | 非公開。ログインした本人しか譜面を見られない |
| 譜面の入手 | 自分で入力・貼り付けする（他サイトから自動取得しない） |
| プラットフォーム | Web（スマホ最適化）。PWA としてホーム画面に追加でき、オフラインでも弾ける |
| 使う端末 | PC で入力・編集し、スマホ／タブレットを譜面台に置いて弾く想定。**端末間でデータを同期する** |
| 対応楽器 | ギター、ピアノ／鍵盤 |
| 収益化 | しない（広告・課金なし） |
| 開発体制 | 個人開発（＋AI 支援） |
| 運用コスト | 無料枠〜月数百円程度に収める |

> 利用者・入力方法・同期の有無は確認前の**仮置き**。違っていれば 9 章で調整する。

### 2.1 権利まわりで守ること（最小限）
個人で楽しむための複製は私的使用の範囲だが、次をすると外れやすいので**仕様として禁止・非対応にする**。

- 譜面を公開 URL で見られるようにする（共有リンク、公開ページ、検索エンジンへの露出）
- 他人とのアカウント共有、歌詞入り譜面の共有機能
- U-FRET・楽器.me などからのスクレイピング（各サイトの利用規約で禁止されている）

YouTube は公式の埋め込みプレーヤー（IFrame Player API）のみで使い、音声の抜き出しはしない。

## 3. 利用シーン

1. **登録する**: 弾きたい曲の譜面テキストを PC で貼り付ける（またはエディタで耳コピしながら書く）。キー・BPM・参考動画の URL を入れる
2. **下準備する**: 動画を流しながらタップして、譜面の各行がどこで始まるかを記録する（同期データ作り）
3. **弾く**: スマホ／タブレットで曲を開く。動画に合わせて譜面が進む。難しいところはループし、速度を落として練習する
4. **振り返る**: どの曲をどれだけ練習したか見る。セットリストを組んでライブや弾き語りの準備をする

---

## 4. 機能要求

優先度: **M** = Must（最初のバージョンに必須）／ **S** = Should（早めに入れたい）／ **C** = Could（余裕があれば）

### 4.1 譜面の登録・編集
| ID | 要求 | 優先度 |
|---|---|---|
| F-EDIT-01 | テキスト貼り付けで取り込む。「コード行＋歌詞行」の2段形式（よくある耳コピテキストの形）と ChordPro 形式（`[C]歌詞`）を自動判別して変換する | M |
| F-EDIT-02 | エディタで編集する。テキスト記法で直接書けて、プレビューを並べて確認できる | M |
| F-EDIT-03 | 曲情報（曲名・アーティスト・元キー・カポ・BPM・拍子・参考動画 URL・メモ）を登録する | M |
| F-EDIT-04 | セクション（イントロ・Aメロ・サビなど）を指定できる | M |
| F-EDIT-05 | 取り込めなかったコード表記（解釈できない文字列）を警告する | S |
| F-EDIT-06 | 歌詞なしのコード進行だけの譜面（小節区切り）も書ける | S |
| F-EDIT-07 | 歌詞の上の任意位置にコードを置ける WYSIWYG 編集（タップでコードを挿入） | C |
| F-EDIT-08 | 画像／PDF の譜面を読み取ってテキスト化する | C |

### 4.2 譜面の表示
| ID | 要求 | 優先度 |
|---|---|---|
| F-VIEW-01 | 歌詞とコードを揃えて表示する（コードは歌詞の該当位置の上） | M |
| F-VIEW-02 | 登場するコードのダイアグラムを一覧表示する（ギター／鍵盤を切り替え） | M |
| F-VIEW-03 | 文字サイズ変更、ライト／ダーク | M |
| F-VIEW-04 | 演奏モード: 操作パネルを最小化し、譜面を画面いっぱいに表示する | M |
| F-VIEW-05 | 段組み表示・コードのみ表示など、スクロールを減らす表示 | S |
| F-VIEW-06 | 印刷／PDF 出力 | C |

### 4.3 演奏支援（基本）
| ID | 要求 | 優先度 |
|---|---|---|
| F-PLAY-01 | 自動スクロール（速度調整、一時停止、タップで再開） | M |
| F-PLAY-02 | 移調（±半音。♯／♭はキーに合わせて自動選択） | M |
| F-PLAY-03 | カポ設定（カポ位置に合わせて表示コードを変換） | M |
| F-PLAY-04 | 簡単コード提案（押さえにくいコードが最も少なくなるカポ位置を提案） | M |
| F-PLAY-05 | 演奏中に画面が消えない（Wake Lock） | M |
| F-PLAY-06 | テンションなどを省いたシンプル表記への切り替え | S |
| F-PLAY-07 | Bluetooth ページめくりペダル（キー入力として届くもの）でのスクロール操作 | S |

### 4.4 練習機能
| ID | 要求 | 優先度 |
|---|---|---|
| F-PRAC-01 | **音源同期スクロール**: 参考動画（YouTube）を埋め込み、再生位置に合わせて譜面の現在行をハイライトし、スクロールする | M |
| F-PRAC-02 | 同期データの作成: 動画を再生しながら、行の頭でタップしてタイムスタンプを記録する。あとから微調整できる | M |
| F-PRAC-03 | 区間ループ（A–B 指定。セクションをタップして指定も可） | M |
| F-PRAC-04 | 再生速度変更（YouTube プレーヤーが対応する範囲、例: 0.5〜1.0 倍） | M |
| F-PRAC-05 | コード音の再生（ダイアグラムやコード名をタップすると鳴る。ギター／ピアノ音色） | M |
| F-PRAC-06 | メトロノーム（曲の BPM・拍子を初期値にする） | M |
| F-PRAC-07 | カウントイン | S |
| F-PRAC-08 | 伴奏再生（BPM に合わせてコード進行を鳴らす。動画なしで練習できる） | S |

### 4.5 ライブラリ・練習管理
| ID | 要求 | 優先度 |
|---|---|---|
| F-LIB-01 | 曲一覧（検索、アーティスト別、最近弾いた順） | M |
| F-LIB-02 | お気に入り | M |
| F-LIB-03 | セットリスト（作成・並べ替え・順番に開く） | M |
| F-LIB-04 | 曲ごとの設定を保存（移調・カポ・スクロール速度・ループ区間・表示設定） | M |
| F-LIB-05 | タグ（例: 弾き語り、練習中、レパートリー） | S |
| F-LIB-06 | 練習記録（開いた日時・練習時間を自動記録。カレンダーや連続日数で表示） | S |
| F-LIB-07 | 苦手コードの登録と、それを含む曲の一覧 | C |
| F-LIB-08 | 使用コードでの絞り込み（例: F を使わない曲） | C |

### 4.6 データ管理
| ID | 要求 | 優先度 |
|---|---|---|
| F-DATA-01 | 端末間の同期（PC で入れた譜面がスマホで見られる） | M |
| F-DATA-02 | オフラインで閲覧・演奏できる（YouTube 同期は除く）。オフライン中の編集は再接続時に同期 | M |
| F-DATA-03 | 全データのエクスポート／インポート（JSON と ChordPro テキスト）。バックアップと、将来の乗り換えのため | M |
| F-DATA-04 | ログイン（自分だけ使えればよい。ソーシャルログイン1種類か、パスキー） | M |

### 4.7 対象外（作らないもの）
- 譜面の公開・共有、他ユーザーとのやりとり
- 他サイトからの譜面の自動取得
- 広告、課金、会員プラン
- 投稿のモデレーション、通報、管理画面
- SEO

## 5. 非機能要求

| 分類 | ID | 要求 |
|---|---|---|
| 性能 | NF-01 | 譜面を開いてから表示まで 1 秒以内（2回目以降はキャッシュから即時） |
| 性能 | NF-02 | 移調・カポ・表示切り替えは端末内で即座に反映する（サーバーに問い合わせない） |
| 性能 | NF-03 | 音源同期のずれ ±100ms 以内 |
| UX | NF-04 | スマホ縦・横、タブレット、PC で使える。演奏中の操作ボタンは大きく押しやすい |
| UX | NF-05 | 対応ブラウザ: iOS Safari／Android Chrome／PC Chrome の最新版 |
| 信頼性 | NF-06 | データを失わない（サーバー側に保存＋手元にエクスポートできる） |
| セキュリティ | NF-07 | 本人以外は譜面にアクセスできない。検索エンジンにインデックスさせない（`noindex`） |
| 運用 | NF-08 | マネージドサービス中心で、放置しても動き続ける。運用コストは月数百円以内 |
| 保守 | NF-09 | 譜面データ形式を文書化し、移調しやすい（キーに依存しない）構造にする |

## 6. リリース計画（案）

自分用なので、使えるところから順に出して、実際に弾きながら改善する。

| ステップ | 目安 | 内容 | この時点でできること |
|---|---|---|---|
| **1. 弾ける** | 2〜3週間 | テキスト取り込み、表示、移調・カポ・簡単コード、自動スクロール、ダイアグラム、曲一覧 | 既存サイトの代わりに譜面を見て弾ける |
| **2. 持ち歩ける** | +2週間 | ログイン・同期、PWA・オフライン、曲ごとの設定保存、エクスポート | PC で入れてスマホで弾ける |
| **3. 練習できる** | +3〜4週間 | YouTube 同期スクロール・同期データ作成、ループ、速度変更、コード音、メトロノーム | 原曲に合わせて練習できる |
| **4. 続けられる** | 以降 | セットリスト、タグ、練習記録、伴奏再生、ペダル対応、印刷 | 練習の積み重ねやライブ準備に使える |

---

## 7. リスク

| リスク | 対策 |
|---|---|
| 貼り付けるテキストの形式がばらばらで、うまく変換できない | 変換できなかった箇所を警告し、エディタですぐ直せるようにする。よく使う形式から順に対応する |
| 埋め込みが禁止された YouTube 動画がある | 動画 URL を曲ごとに差し替えられるようにする。伴奏再生・メトロノームを代替手段にする |
| 同期データ作りが面倒で使わなくなる | タップだけで作れる操作にする。行単位の粗い同期から始める |
| 作り込みすぎて完成しない | ステップ 1 を最短で作って、実際に使いながら優先度を見直す |

---

## 8. 用語

| 用語 | 意味 |
|---|---|
| カポ | ギターのフレットを押さえて音程を上げる器具。押さえやすいコード形で弾ける |
| 簡単コード | カポなどで、押さえにくいコード（F などのバレーコード）を減らした表記 |
| 音源同期スクロール | 動画の再生位置に合わせて、譜面の現在位置を自動で追いかける機能 |
| ChordPro | コード譜をテキストで書く記法（例: `[C]歌詞[G]歌詞`） |
| PWA | ホーム画面に追加でき、オフラインでも動く Web アプリ |

## 9. 確認したいこと（仮置きしている前提）

1. **利用者**: 自分だけで良いか（家族やバンド仲間も使うなら、各自が自分の譜面を持つ形にする。歌詞入り譜面を互いに共有するのは私的使用を超えやすい）
2. **端末間の同期**: 必要か（不要なら、サーバーなしで端末内保存だけの最小構成にでき、さらに簡単になる）
3. **譜面の入力方法**: テキスト貼り付け＋エディタで足りるか。画像読み取りは優先度を上げたいか
4. **ステップ 1 に入れたい機能**: 上の計画で良いか（例: YouTube 同期を最初から欲しいか）
5. **技術スタック**: 要求が固まったら別途決める
